# Operations runbook

## Installation

1. Run `just setup`; this installs requirements from the vendored Kubespray
   copy and does not clone another repository.
2. Run `just inventory` to map the four existing Project 1 instances into the
   Project 2 Kubespray inventory. No EC2 instances are created.
3. Confirm `just ping`, then run `just cluster`. This is an in-place migration:
   it stops and disables Project 1's NGINX and Docker services and disables its
   host-level UFW rules, while retaining Docker volumes and application data on
   disk. The wrapper then executes
   `infra/kubespray/cluster.yml` against only
   `infra/kubespray/inventory/project02/hosts.yml`.
4. Configure `infra/platform-config.yml`, create and encrypt `infra/vault.yml`,
   then run `just complete`. The recipe uses the administrator kubeconfig
   generated by Kubespray, registers only `master02`, `worker01`, and
   `worker02` behind the existing AWS NLB, installs the platform, bootstraps
   Argo CD, and runs `40-verify.yml`.
5. Run `just argocd-credentials` from the controller. It connects to
   `master01` and decodes the password from `argocd-initial-admin-secret` using
   the control-plane kubeconfig. Then sign in as `admin` and rotate or disable
   the initial administrator credential according to the operating policy.
6. To rotate webhook verification independently, update
   `vault_argocd_webhook_secret` using `just generate-webhook-secret` followed
   by `just vault-edit`, then run `just argocd-webhook-secret`. This
   synchronizes Argo CD and GitHub.

## Required external configuration

Configure DNS for Headlamp, Argo CD, and the application against Traefik's
external address. A self-managed cluster needs a functional load-balancer
implementation (for example a cloud controller or MetalLB with reserved
addresses); a pending `LoadBalancer` service is not acceptable evidence.

## Verification

Record node readiness and taints, system pod health, etcd member/endpoint
health for all three members, Traefik ingress class, certificate readiness, Headlamp RBAC denial,
Argo CD `Synced/Healthy`, application release identifier, CI scan, immutable
digest promotion, and Git-revert rollback.

## Etcd backup and recovery

Use the exact snapshot and restore commands documented for the pinned
Kubespray/etcd release. Encrypt snapshots and copy them off-cluster. A backup is
not accepted until restored in a disposable environment. The three-member
baseline tolerates one etcd member failure, but recovery must still be tested.

## Reset

Export evidence first. Remove Argo CD Applications/finalizers intentionally,
then run `99-reset.yml` only with the explicit lab confirmation. Cloud instance
destruction remains owned by Project 1 because these are Project 1 instances.
Do not run Project 2's legacy VM destruction playbook against reused machines.
